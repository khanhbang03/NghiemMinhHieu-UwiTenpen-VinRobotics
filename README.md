1. **README.md siêu ngầu:** Tránh xa các kiểu mô tả khô khan. Sử dụng badge động, emoji, ảnh GIF, và những câu tuyên ngôn đanh thép.
2. **Cấu trúc Folder sạch bong:** Code có thể đang dính bug, nhưng cấu trúc file thì phải ngăn nắp như khách sạn 5 sao.
3. **Các file tiêu chuẩn nhưng viết theo phong cách chất:** File `LICENSE`, `CONTRIBUTING.md`, và đặc biệt là file thông báo lỗi (`ISSUE_TEMPLATE`).
